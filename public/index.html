02 / CONNECTION

Timing source

The direct VOLA connection is experimental. Verify it on the timing computer before the race.

VOLA event codes (advanced)

The default maps start and finish events. DNF and DSQ codes are unverified: add only numeric codes confirmed by the timing operator. Allowed values: start, finish, dnf and dsq. Unknown codes are ignored.

Default port: 8789. Copy the key from the bridge. Names, clubs, birth years and results come from VOLA. Supports race automation when start reading is enabled in the bridge. Validate the live VOLA mapping before racing.

Test-feed overlays always display a test badge in the selected broadcast language.

03 / RACE SETUP

Race settings

Shown on racer and Top 10 overlays. Up to 120 characters.

Shown as a red discipline badge on racer and Top 10 overlays. Other hides the badge.

Changes overlay text and previews. Race control stays in English.

Automatic display switching

A finish, DNF or DSQ takes the main card. Next, the racer who started first is shown. When the course is empty, the last racer’s category Top 10 is shown.

Categories with results rotate only when the course and finish queue are empty. A new start returns to the racer view.

Competitors

In a CSV, only bib (the racer’s bib number) is required. Optional columns: name,category,club,yearOfBirth for name, category, club and birth year. Tab-separated VOLA TXT rosters are also supported. Missing details are hidden on overlays. The roster is saved locally.

Fetch a CSV or VOLA TXT file and save a local copy. The roster does not update automatically during a race.
